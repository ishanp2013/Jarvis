      Memory and privacy

        Microsoft: Outlook.com mail, Calendar and To Do

        Official Microsoft sign-in (Microsoft Graph). You need a free app registration first; see SETUP.md.

        Classic Outlook (desktop)

        Reads accounts already set up in classic Outlook, including Gmail over IMAP. No cloud setup needed. Classic Outlook must be installed and signed in.

        Discord (bot)

        Uses your own Discord bot, invited only to the servers you choose. It can't read your personal DMs.

        WhatsApp

        There is no official way to read personal WhatsApp chats. Jarvis can only draft a message and open WhatsApp with it filled in; you press Send.
